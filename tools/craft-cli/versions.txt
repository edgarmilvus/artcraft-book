# Engine versions pinned for the whole repository.
#
# One line per engine: <app> <version>. This file is the single source of
# truth: tools/install_craft_clis.sh reads it for the native install, and the
# Dockerfile reads it when it builds the image, so the two cannot drift.
#
# To bump an engine:
#   1. change the version here;
#   2. update tools/craft-cli/SHA256SUMS with `shasum -a 256` of the new
#      binary, using the same layout (`<sha>  <app>-cli`);
#   3. rebuild the image and, if the vendor's releases moved, re-upload the
#      mirror archives to the `craft-cli-v1` release.
