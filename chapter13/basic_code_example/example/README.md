# 13. Basic Code Example

A single-file demonstration of the FilmCraft three-way color wheel +
sidechain ducking + loudness governance pipeline. It creates a timeline
with two video tracks (B-roll, graphics) and two audio tracks (dialogue,
music), applies a color grade to the B-roll track, ducks the music under
the dialogue, normalizes to ‑16 LUFS, and exports an MP4.

## What it does

`01_filmcraft-threeway-ducking.ts` opens `filmcraft-cli mcp`, creates a
project, adds tracks, places clips, applies a `colorWheels` adjustment
layer to the video track, adds a `sidechain` compressor to the music track
keyed to the dialogue track, runs `audio.loudness.normalize`, and exports.
The harness asserts the output MP4 exists, has the correct duration, and
the loudness measurement matches the target.
